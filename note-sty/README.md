# latexzero-note style

Download `latexzero-note.sty` to the same directory as your document and select
a style with the `style` option:

```latex
\documentclass{article}
\usepackage[style=leftsidebox]{latexzero-note}

\begin{document}

...

\end{document}
```

Available styles are `simple`, `box`, `leftsidebox`, and `borderless`. The
default is `box`.
